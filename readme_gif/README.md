# Анимированные схемы

## Схемы Pi

| Файл | Содержание | Длительность |
| --- | --- | --- |
| `pi_install.gif` | Папка на D, установка Pi, конфигуратор и первый запуск | Около 12 секунд |
| `pi_adapters.gif` | Общие правила и отдельные реализации шлюза | Около 13 секунд |
| `pi_sessions.gif` | Служба, пауза всей задачи, смена моделей и продолжение | Около 18 секунд |
| `pi_parallel.gif` | Отдельные копии исполнителей, проверка и перенос | Около 13 секунд |

Это поясняющие схемы с примером состояния, а не запись экрана. Они не заменяют
проверку сценария в продукте. Все четыре включены в русский README;
первые три — также в английский. Кадр 1200×675, анимация зациклена.

Источник — [build_pi_explainers.py](source/build_pi_explainers.py).
Он использует Pillow и исходный `gifkit.py`: те же шрифты Segoe UI/Consolas,
цвета, карточки, стрелки, шаги и подписи, что в оригинальном проекте.
Новые функции названы по действию и не требуют знакомства со всем исходным набором.

Пересобрать из корня репозитория:

```powershell
python -B readme_gif/source/build_pi_explainers.py
```

Нужны Python с Pillow и шрифты Windows. Устанавливать Pillow в системный Python
не требуется: можно использовать отдельную среду для документации.
Для другого каталога результатов:

```powershell
python -B readme_gif/source/build_pi_explainers.py --output-directory D:\Temp\pi-gif
```

Скрипт сохраняет четыре GIF и `pi_review_frames.png` со всеми последними кадрами
шагов. Лист кадров нужен для просмотра вёрстки; он не входит в поставку,
но создаётся заново при пересборке.
Для точного повторения убери переменную `GIF_LANG`, если задавал её для старого набора.

При подготовке текущего набора использован уже установленный Pillow 12.3.0 из
среды инструментов; зависимости приложения из-за GIF не менялись.

## Унаследованные схемы OpenCode

Файлы `01_install.gif` … `08_dashboard.gif`, записи мастера установки и папка `en`
сохранены из оригинала. Они описывают OpenCode, а не Pi. Скрипты `s01_install.py`
… `s08_dashboard.py` и более ранние `gif1_planning.py` … `gif5_dashboard.py`
оставлены для изучения и истории.

Старый набор собирается из `readme_gif/source`:

```powershell
python -B s02_team.py
```

Для английского варианта старых схем задаётся `GIF_LANG=en`; словарь находится
в `i18n_en.py`. Новые Pi-схемы сейчас только на русском, что явно указано
в английском README.

## Запись живого примера

pi_game_live.gif собран из семи снимков настоящего браузера: пустое поле,
пять ходов с победой X и новая игра. Это отдельная запись приложения.
Кадры сохранены в source/pi_game_frames, сборка — в source/build_pi_game_recording.py.

```powershell
python -B readme_gif/source/build_pi_game_recording.py
```

Нужен Pillow. Скрипт сохраняет порядок состояний и вырезает область игры из
полного снимка страницы. Исходные кадры остаются без изменений.
