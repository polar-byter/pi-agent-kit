# Крестики-нолики из живого прогона

Здесь сохранены принятые исходники проверочного проекта Pi. Они совпадают с
файлами отдельного проекта pi-tic-tac-toe; журналы и ключи в пример не входят.

На Windows открой play.cmd и затем http://127.0.0.1:8765.
На Linux запусти sh play.sh. Другой порт: play.cmd --port 8766.
Оба сценария используют отдельный Python кита на диске репозитория.
Зависимостей pip или npm у самой игры нет.

Из этой папки полный набор проверок запускается так:

```powershell
..\..\kit\python.cmd -B -u -m unittest discover -s tests -v
```

На Linux: sh ../../kit/python.sh -B -u -m unittest discover -s tests -v.
Набор содержит 20 тестов правил, HTML и настоящего локального HTTP-сервера.

Правила находятся в game_rules.py, страница — в game_page.py, HTTP — в server.py.
При чтении сначала пройди один ход от POST /move до нового состояния и HTML.
ARCHITECTURE.md — план, сохранённый настоящим DeepSeek-архитектором до реализации.
Тела функций получены через изолированные попытки MiMo и DeepSeek Bug Fixer.
Подробный отчёт находится в ../../docs/kit/PI_LIVE_SCENARIO.ru.md.
