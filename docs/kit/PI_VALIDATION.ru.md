# Проверки адаптации Pi

Итог на 19 октября 2026 года. Здесь приведены результаты именно Pi-адаптации.
Результаты исходного OpenCode-проекта сохранены отдельно в истории.

## Общий прогон

Последний завершённый общий набор: **766 тестов за 159.484 с, OK,
пропусков — 1**. Набор включает ядро, конфигуратор Tk, дашборд,
установщик, шлюз Pi и нативную проверку установленного Pi 1.3.0.
Парсер самого кита сохраняет для такого прогона status=skipped и category=incomplete. Правило строгой приёмки не ослаблялось; полностью зелёным этот общий прогон в журнале не отмечен.

Единственный пропуск связан с недоступной текущему пользователю Windows
привилегией создания символических ссылок. Проверки junction и жёстких ссылок
в доступных сценариях выполнены.

Команда из корня репозитория:

```powershell
$env:PI_KIT_NATIVE_SMOKE = '1'
.\kit\python.cmd -B -u -m kit.test_completed
```

Чтобы сохранить все временные файлы на D, перед запуском можно задать TEMP и TMP
как существующую папку на D. В выполненных прогонах использовалась .tools/temporary.
Базовые тесты не выполняют платную генерацию. Отдельный живой сценарий ниже
использовал явно разрешённый ключ OpenRouter.

Локальный журнал последнего набора: `.metrics/browser-report-validation-20261019/full-suite.log`.
Журналы исключены из Git. В других копиях репозитория этот локальный файл
может отсутствовать; команду можно выполнить заново.

## Найденные и исправленные ошибки

- На Windows Чиф получал Bash через WSL, хотя Linux-дистрибутив не был установлен.
  Теперь ему назначается нативный инструмент PowerShell; исполнителю shell по-прежнему недоступен.
- Чтение первого байта файла перед Windows record lock конфликтовало со вторым клиентом.
  Инициализация проверяет размер; здоровое соединение обходится без блокировки запуска.
- При включённом исправителе инфраструктурный повтор исполнителя ошибочно запрещался.
  Теперь подтверждённая blocked-попытка продолжается той же ролью через exact previous ID.
- Завершение уже погибшей службы пыталось обратиться к оставшемуся HTTP-порту.
  Теперь сверяется PID с идентичностью процесса и удаляются только устаревшие метаданные.
- Метаданные соединения с неверными типами или без идентичности процесса отклоняются.
- Консоль не обрабатывала TaskHalted при вводе задания на паузе.
  Однократный режим возвращает код 3; интерактивный сохраняет доступ к локальным командам.
- Дашборд Pi показывал названия и подсказки OpenCode. Названия и переводы теперь соответствуют выбранной среде.
- Завершённая задача сохраняла старую подсказку продолжения. Она скрыта; актуальные ошибки управления остаются видимыми.

Дополнительно исправлена подпись расхода Bug Fixer: роль теперь берётся из attempt_session и session_usage, включая общий идентификатор модели у разных ролей.

Для этих изменений добавлены регрессионные проверки. Ранний прогон на 698 тестах
содержал три неуспешных проверки и две ошибки. Их причины устранены; его числа
не подменяются задним числом результатом нового прогона.

## GitHub Actions

Проверка Pi Kit на Windows готовит закреплённый частный Python, устанавливает
локальный Pi и запускает общий набор без платной генерации. Старый Linux workflow
сохранён как ручная проверка исторического OpenCode-пакета. Его результаты
не считаются проверкой Linux-адаптации Pi. Состояние удалённого CI проверяется
отдельно от приведённых выше локальных результатов.
