В папках `user` и `kit` сохранены руководства исходного OpenCode-проекта.
В начале каждого такого файла есть пометка. Они полезны для изучения журнала,
приёмки, метрик и других общих механизмов, но описания запуска и API сессий
относятся к прежней среде. При расхождении с Pi-руководствами следуй Pi-руководствам.

[Исходный README](history/OPENCODE_README.ru.md) показывает, как был описан
базовый проект до адаптации. [SOURCE.md](../SOURCE.md) фиксирует исходный коммит,
лицензию и происхождение кода.
