# Первый проект с OpenCode Kit

Для работающего проекта доступна [смена моделей и API без новой задачи](LIVE_MODELS.ru.md):
пауза → настройки моделей → сохранить и подготовить → продолжить.
При ошибке квоты дашборд показывает предупреждение и сам ставит задачу на паузу.

Кит — набор правил и инструментов для работы нескольких моделей. Чиф составляет
план, исполнители пишут код, Bug Fixer исправляет неудачные реализации, а дашборд
показывает ход работы и расход токенов. Токен — единица текста, которую считает модель.

## Установка на Windows

![Мастер установки](../../readme_gif/01_install_live.gif)

1. Скачайте **Desktop для Windows** с [официальной страницы OpenCode](https://opencode.ai/download), установите и откройте его. Нужен Desktop 2.x. Консольная версия CLI — отдельный интерфейс, сама по себе она не заменяет Desktop.
2. Python отдельно устанавливать не нужно: при первом запуске кит скачает и проверит закреплённую версию **3.13.16** с официального python.org. Нужен интернет; другие установки Python сохраняются.
3. На [странице репозитория](https://github.com/polar-byter/opencode-environmental-tune) нажмите **Code → Download ZIP**. Полностью распакуйте архив в отдельную папку. Не запускайте файлы внутри ZIP.
4. В распакованной папке дважды нажмите **install.cmd**. Сначала появится окно подготовки Python, затем графический мастер. При повторном запуске загрузка не нужна.
5. В шаге 1 мастер покажет найденный Desktop. Если его нет, нажмите **Скачать OpenCode**, установите и затем **Проверить ещё раз**. Для нестандартного пути используйте **Выбрать приложение…** и укажите `OpenCode.exe`.
6. В шаге 2 выберите папку своего приложения либо введите новый полный путь, например `D:\Projects\my-home-app`. Мастер сам создаст отсутствующие папки. Выбирайте папку вне скачанного кита. Можно использовать папку со своим кодом: конфликтующие настройки кита не перезаписываются, мастер объяснит проблему.
7. Нажмите **Создать проект и настроить модели**. Мастер скопирует кит и откроет конфигуратор — окно выбора моделей и API.

## Выбор моделей и API

В конфигураторе есть три роли:

| Роль | Для чего | Начальный выбор шаблона |
|---|---|---|
| Master Chief | Архитектура, задания, проверка кода и тесты | OpenCode DeepSeek V4.1 Flash Free |
| Исполнитель | Реализация небольшого задания | OpenCode MiMo V2.6 Flash Free |
| Bug Fixer | Одна попытка исправления после дефекта или лимита исполнителя | OpenCode DeepSeek V4.1 Flash Free |

Доступность моделей меняется: если выбранная модель недоступна, выберите доступную
в конфигураторе. По умолчанию исполнителей **2**: независимые задания идут
параллельно; **1** — строго по очереди. Каждый работает в отдельной копии файлов, Чиф принимает и
объединяет результат. Это не разрешает одновременную запись в общие файлы.

Для каждой роли выберите источник:

- **OpenCode** — модель из доступного каталога OpenCode. Если провайдер требует входа, сначала подключите его в OpenCode.
- **LM Studio** — локальная модель на вашем компьютере. Запустите сервер LM Studio и загрузите модель перед проверкой соединения.
- **API** — внешний сервис с OpenAI-совместимым интерфейсом: укажите адрес, точный ID модели и свой API-ключ. Ключ — секрет доступа к сервису; не вставляйте его в чат или Git. Конфигуратор хранит ссылку на переменную окружения, а не ключ в проекте.

Проверьте соединение соответствующей кнопкой. Затем нажмите **Сохранить** и
**Подготовить OpenCode**. Сохранение записывает ваш выбор, подготовка создаёт
рабочую конфигурацию OpenCode. Ждите успешного результата; при ошибке прочитайте
сообщение и исправьте адрес, ключ или доступность модели. Новые настройки применяются
в новой сессии. После добавления нового ключа полностью закройте и откройте Desktop.

## Открытие проекта и первое задание

После успешной подготовки мастер сам запускает Desktop с запросом открытия выбранной
папки. В некоторых версиях Desktop ссылка открытия не выбирает папку. Поэтому
проверьте имя проекта в Desktop; если оно другое, нажмите в мастере **Копировать путь**,
в Desktop выберите **Open Project** и вставьте путь. Запуск процесса сам по себе не
подтверждает, что нужная папка открыта.

Откройте **новый чат** в этой папке и выберите основного агента **build**. Скопируйте
задание из шага 4 мастера, измените его под себя и отправьте. Мастер не отправляет
промпты автоматически. Промпт — обычное текстовое задание модели. Например:

```text
Создай локальное приложение для домашних дел и расписания дня.
Нужны список дел с датами и статусами и таблица дня с колонками:
время начала, время окончания, занятие. Время обязательно видно в таблице.
Добавление, изменение и удаление записей; проверка пересечений времени.
Данные храни в SQLite и сохраняй между запусками. Интерфейс — на русском,
с понятными подписями, контрастным текстом и удобной навигацией.
Следуй правилам кита. Сам составь архитектуру и план в currentsteps.md,
подготовь тесты, поручай реализацию настроенным исполнителям и выполни план.
Проверь работу модулей и полный набор тестов, затем сделай ревизию интерфейса.
Подготовь файл запуска и объясни, как пользоваться приложением.
```

Файл `TASK.md` необязателен: задание в чате достаточно. Дашборд откроется при
регистрации задачи Чифом. Подождите запуска работы, при вопросе Чифа ответьте в чате.
Готовность подтверждается принятыми заданиями и успешными полными тестами.

## Что появится в папке

| Файл или папка | Назначение |
|---|---|
| `AGENTS.md` | Правила агентов и проектный план `currentsteps.md` |
| `opencode.jsonc`, `.opencode/commands/` | Основная настройка OpenCode и команды |
| `kit/` | Конфигуратор, контроллер исполнителей, метрики и дашборд |
| `.opencode/kit-models.json` | Ваш выбор моделей, без API-ключей |
| `.opencode/opencode.jsonc` | Конфигурация, созданная подготовкой |
| `.metrics/` | Локальные журналы задач и настройки интерфейса |
| `docs/user/` | Руководства пользователя, включая это (RU/EN) |
| `docs/kit/` | Как устроен кит: метрики, проверка работы, исполнители |

Язык мастера и дашборда определяется окружением; можно выбрать English или Русский.
Язык текстов, которые пишет модель, определяется заданием. Повторный запуск мастера
для уже созданного им проекта открывает настройки, сохраняя код и выбранные модели;
это не обновление версии кита.

Для Ubuntu/Debian/Mint предусмотрен графический пакет **opencode-kit_0.2.0_all.deb**:
откройте его мышкой, нажмите «Установить», затем откройте **OpenCode Kit** в меню
приложений. При первом запуске мастер автоматически подготовит личный Python 3.13.16 с Tk; системный Python не меняется. Подробности и границы
поддержки: [установка Linux мышкой](LINUX_INSTALL.ru.md).
Пакет также собирается workflow **Linux installer** в GitHub Actions, артефакт
**opencode-kit-linux-deb**. Для macOS пока остаётся `python3 install.py` с Python и Tk.
